# 정리 (강의 정리 노트)

사용자가 준 강의 자료를 **Claude가 직접 읽고** 아래 형식의 정리 노트로 만든다.
NotebookLM이나 다른 외부 서비스는 쓰지 않는다.
기준 예시는 약리학 Chapter 21 항고혈압약물 정리본이다.

## 진행 순서

1. 자료를 끝까지 읽는다. PDF·PPT·Word·이미지 모두 슬라이드(페이지) 순서를 기록해 둔다.
2. 사용자가 범위를 말했으면(예: "21장만", "ACEi 부분만") 그 범위만 정리한다.
3. 아래 형식으로 정리 노트를 쓴다.
4. 결과는 대화에 마크다운으로 보여 준다. 사용자가 파일(Word, PDF)을 원하면 그 형식으로 만들어 준다.
   Word로 만들 때는 핵심을 형광펜(하이라이트), 강조를 밑줄로 표시해 원본 정리본과 같은 느낌을 낸다.

## 형식

### 1. 표지
- 첫 줄: 과목명 (한글 + 영문). 예) 약리학 Pharmacology
- 장 제목: `# Chapter 번호 한글제목 *English Title*`
  예) `# Chapter 21 항고혈압약물 *Antihypertensive Drugs*`

### 2. 학습 목표
- `## 학습 목표` 아래 번호 목록(1. 2. 3. ...)
- 각 목표의 핵심 키워드는 **굵게**

### 3. 본문 (슬라이드 순서대로)
- 자료의 흐름을 그대로 따르고, 주제마다 `## 소제목`으로 나눈다
- 줄글 대신 짧은 개조식: 큰 항목은 `➢`, 세부 항목은 `-`
- 기전·인과관계는 화살표 연쇄, 증감은 ↑ ↓
  예) `Na⁺·수분 배설↑ → 혈액량↓ → 심박출량↓ → BP↓`
- 중요한 공식은 한 줄로 따로. 예) `Blood pressure = CO Ⅹ Peripheral resistance`
- 어려운 개념 바로 아래에 `= 쉬운 말 풀이` 한 줄
  예) `심근수축력·심박수↓` 아래에 `= 심장이 일을 덜 하게 함`

### 4. 표 정리 (가장 중요)
- 약물(또는 질환·개념) 그룹마다 표로 정리한다
- 단일 그룹 표: 왼쪽 열 = 항목, 오른쪽 열 = 내용
  항목 순서: 기전 / 약제 / 효과(적응증) / 부작용 / 비고(주의·간호)
- 여러 그룹 비교 표: 첫 열 `구분`, 나머지 열 = 비교 대상
  예) `| 구분 | ACEi (-pril) | ARB (-sartan) | 레닌억제제 |`
  행: 약제 / 차단 지점 / 부작용 / 임신 / 장점
- 하위 분류가 있으면 비교 표로 나눈다
  예) CCB → Non-DHP vs DHP, 이뇨제 → Thiazide vs Loop vs 칼륨보존
- 표 바로 아래에 공통점·핵심을 굵은 한 줄로 요약
  예) `**공통: 세동맥 확장 → 말초저항↓ → BP↓ / 자몽주스와 함께 복용 금지**`
- 헷갈리기 쉬운 개념은 `※`로 시작하는 한 줄 주의
  예) `※ AT1 = 안지오텐신 Ⅱ의 '제1형' 수용체 (안지오텐신 Ⅰ의 수용체가 아님)`

### 5. 표기 규칙
- 한글과 영문(약어) 병기. 예) 심박출량 Cardiac Output(CO), 안지오텐신 전환효소 억제제(ACEi)
- 약물은 영문 일반명 + 대표 상품명. 예) Amlodipine(노바스크), Furosemide(Lasix)
- 같은 계열 약물의 공통 어미는 굵게. 예) Capto**pril**, Lo**sartan**, Amlo**dipine**, Ate**nolol**, Pra**zosin**
- 시험에 나올 핵심(금기, 대표 부작용, 첫 용량 효과, 반동 현상, 임의 중단 금지 등)은 **굵게**
- 자주 쓰는 약어(HT, BP, HR, SV, CO, IV 등)는 처음 한 번만 풀어 쓰고 이후 약어로

### 6. 임상 적용 / 간호
- 상황별 우선 선택 표: `| 환자 상황 | 우선 고려 약물 | 이유 |`
- 응급·투여 약물 표: `| 약물 | 투여 | 작용 시간 | 간호 포인트 |`
- `## 환자 안전과 교육`: 모니터링, 부작용 교육, 보고해야 할 증상, 병용 주의, 순응도를 `➢` 개조식으로

### 7. 핵심용어
- 마지막에 `## 핵심용어`를 두고 `용어 (약어): 한 줄 정의` 목록으로 정리

## 지킬 것

- 자료에 없는 내용은 지어내지 않는다. 수치·약물명·용량은 자료 그대로 옮긴다.
- 자료에 있는 그림·도식은 내용을 글이나 표로 풀어 쓴다.
- 자료가 약리학이 아니어도 같은 구조를 쓴다. 약물 대신 그 과목의 개념·질환·이론을 그룹으로 묶어 표로 만든다.

## 예시 (일부)

```markdown
## ACEi vs ARB

| 구분 | ACEi (-pril) | ARB (-sartan) |
|---|---|---|
| 약제 | Capto**pril**, Enala**pril**, Rami**pril** | Lo**sartan**, Val**sartan**, Irbe**sartan** |
| 차단 지점 | ACE: Ang Ⅰ → Ang Ⅱ 전환 차단 | AT1 수용체 차단 |
| 브라디키닌 | 분해 억제 → 폐에 축적 | 변화 없음 |
| 부작용 | **마른기침**, 혈관부종, 고칼륨혈증 | 고칼륨혈증, 어지럼 (기침 거의 없음) |
| 임신 | **금기** | **금기** |

= ARB는 ACE 효소는 그대로 두고 수용체만 막아서 마른기침이 없음

※ AT1 = 안지오텐신 Ⅱ의 '제1형' 수용체 (안지오텐신 Ⅰ의 수용체가 아님)
```
